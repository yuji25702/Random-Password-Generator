# Random Password Generator - Генератор случайных паролей

## Описание программы

**Random Password Generator** — это GUI-приложение для генерации случайных паролей. Приложение позволяет настраивать длину пароля, выбирать типы символов, сохранять историю генерации в JSON-файл и загружать её при повторном запуске программы.

### Возможности:
- ✅ Генерация случайных паролей
- ✅ Настройка длины пароля с помощью ползунка
- ✅ Выбор типов символов:
  - Буквы
  - Цифры
  - Специальные символы
- ✅ Сохранение истории паролей в JSON-файл
- ✅ Автоматическая загрузка истории при запуске
- ✅ Копирование пароля в буфер обмена
- ✅ Очистка истории
- ✅ Валидация вводимых данных

## Инструкция по запуску

### Требования:
- Python 3.6 или выше
- Установленная библиотека Tkinter (обычно входит в Python)

### Запуск:
1. Откройте терминал или командную строку
2. Перейдите в папку проекта:
   ```bash
   cd random-password-generator
   ```

3. Запустите приложение:
   ```bash
   python main.py
   ```

## Примеры использования

### Генерация пароля:
1. Выберите длину пароля с помощью ползунка
2. Отметьте нужные типы символов:
   - Буквы
   - Цифры
   - Специальные символы
3. Нажмите кнопку **"Generate Password"**
4. Сгенерированный пароль появится в поле вывода

### Копирование пароля:
- Нажмите кнопку **"Copy Password"**
- Пароль будет скопирован в буфер обмена

### Работа с историей:
- После генерации пароль автоматически сохраняется в историю
- История отображается в таблице
- История автоматически сохраняется в файл `passwords.json`
- При следующем запуске данные автоматически загружаются

### Очистка истории:
- Нажмите кнопку **"Clear History"**
- Все сохранённые записи будут удалены

## Валидация данных

Приложение проверяет:
- Минимальная длина пароля — 4 символа
- Максимальная длина пароля — 64 символа
- Должен быть выбран хотя бы один тип символов
- Нельзя сгенерировать пустой пароль
